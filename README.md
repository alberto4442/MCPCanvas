# MCPCanvas

MCPCanvas: A distributed, cloud-native rendering engine utilizing real-time data and auto-scaling on a scalable platform as a service.

MCPCanvas is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/MCPCanvas.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure MCPCanvas, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
